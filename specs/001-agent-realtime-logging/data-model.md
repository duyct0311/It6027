# Data Model & Schema Definitions

## 1. Entity Models

### Agent (`agents` table)
Represents a registered client machine running the scanner software.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `agent_id` | String(64) | Primary Key, Indexed | Unique UUID identifier generated by Agent host |
| `hostname` | String(128) | Not Null | Hostname of the client computer |
| `ip_address` | String(45) | Nullable | IP address reported on WebSocket handshake |
| `status` | String(20) | Default: `'ONLINE'` | Agent connection status: `'ONLINE'` or `'OFFLINE'` |
| `last_seen` | DateTime | Not Null | UTC timestamp of last heartbeat or log stream |
| `version` | String(20) | Nullable | Agent software version (e.g. `"1.0"`) |
| `created_at` | DateTime | Default: UTC Now | Registration timestamp |

---

### ScanLog (`scan_logs` table)
Represents an individual malware detection event or scan result streamed from an Agent.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | Integer | Primary Key, Autoincrement | Internal surrogate key |
| `agent_id` | String(64) | Foreign Key (`agents.agent_id`), Indexed | Originating Agent ID |
| `module` | String(32) | Indexed | Detection engine module: `"AI"`, `"YARA"`, `"Heuristic"`, `"Hash"` |
| `name` | String(128) | Indexed | Name of detected malware threat or rule |
| `path` | String(512) | Indexed | Target file path on agent filesystem |
| `scan_type` | String(64) | Indexed | Type of scan: `"Realtime Protection"`, `"Manual Scan"`, `"Scheduled Scan"` |
| `severity` | String(20) | Indexed | Threat severity: `"Low"`, `"Medium"`, `"High"`, `"Critical"` |
| `status` | String(32) | Indexed | Action outcome: `"DETECTED_ONLY"`, `"QUARANTINED"`, `"DELETED"` |
| `time` | DateTime | Indexed | Original event timestamp reported by Agent |
| `version` | String(20) | Default: `"1.0"` | Protocol payload version |
| `created_at` | DateTime | Default: UTC Now | Server ingestion timestamp |

---

### AdminUser (`admin_users` table)
Represents administrative user credentials for web dashboard access.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | Integer | Primary Key, Autoincrement | Internal user ID |
| `username` | String(64) | Unique, Not Null | Admin login username (`admin`) |
| `hashed_password` | String(255) | Not Null | Bcrypt/Argon2 password hash |
| `role` | String(20) | Default: `'Admin'` | User role (`'Admin'`) |
| `created_at` | DateTime | Default: UTC Now | Creation timestamp |

---

### ScanSchedule (`scan_schedules` table)
Represents an automated periodic scan schedule configured by the Admin.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | Integer | Primary Key, Autoincrement | Schedule ID |
| `name` | String(128) | Not Null | Human-readable schedule title |
| `cron_expression` | String(64) | Not Null | 5-part cron syntax (e.g. `0 2 * * *`) |
| `scan_scope` | String(512) | Not Null | Target filesystem path (e.g. `C:\Program Files`) |
| `target_agents` | String(64) | Default: `'ALL'` | Target scope: `'ALL'` or specific `agent_id` |
| `scan_mode` | String(32) | Default: `'DETECTED_ONLY'` | Action mode: `'DETECTED_ONLY'`, `'QUARANTINE'`, `'DELETE'` |
| `is_active` | Boolean | Default: `True` | Active toggle flag |
| `created_at` | DateTime | Default: UTC Now | Configuration timestamp |

---

## 2. Validation & State Transition Rules

1. **Log Severity Enum**: Must strictly be one of `['Low', 'Medium', 'High', 'Critical']`.
2. **Log Action Status Enum**: Must strictly be one of `['DETECTED_ONLY', 'QUARANTINED', 'DELETED']`.
3. **Agent Status State Machine**:
   - `WebSocket Connect` -> set `status = 'ONLINE'`, update `last_seen`.
   - `WebSocket Disconnect` -> set `status = 'OFFLINE'`, update `last_seen`.
4. **Schedule Cron Expression**: Must validate against standard 5-part cron syntax before persistence.
